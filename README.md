# HS Card Market

Static product landing page for HS Card Market. The page introduces the card-pricing product, its tools, and the product tour. This repository contains the marketing site rather than the inventory or pricing backend.

## Run locally

```sh
python -m http.server 8000
```

Open http://localhost:8000. No build step is required.

## Files

- `index.html`: landing page, styles, and browser interactions.
- `howto.mp4`: product-tour video.
- `poster.jpg`: video poster.
- `logo.png` and `logo-sm.png`: branding assets.
- `CNAME` and `.nojekyll`: static-hosting configuration.
